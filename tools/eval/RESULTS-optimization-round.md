## 0. 一句话结论

1. **评分/选择规则层已经封顶**：把真值掩膜下采样成"完美显著度图"喂进同一套代码，保留率再涨的空间只剩 **10%~40%**；余量的 **59%~90% 都在显著度层**。所以换模型是唯一的大杠杆，调权重/加分辨率只能捡零头。
2. **换 RMBG-1.4 在 DUTS-TE `src` 上把这块余量吃掉了 98.9%**（A 0.9753 → 0.9899，完美先验 B = 0.990081）；但**收益随口径递减、并非全面胜利**：DUT-OMRON 3:4 反而 **−0.0091**，ECSSD 两档转负，三分线（构图）在 ECSSD / DUT-OMRON 上一致变差。
3. **提升网格分辨率不是瓶颈**：64×48 → 256×192，算法保留率净增只有 **+0.0008**，完美先验只涨 **+0.0012**，且构图单调略差。要动只值得动到 128×96。
4. **现有目标函数 `kept_ratio` 有退化解**（"不裁"＝整图＝1.0，候选集 argmax 100% 落在整图框）。替代度量里 `F` 在同尺寸对照下与 `kept` **逐图等价**（5019/5019 同号），真正提供新视角的是 **`H`（含构图项）** 与 **`Rc`（构图达标下的保留率）**。

## 3. 第 2 条：提升显著度网格分辨率

评估网格固定为候选框几何（64×48），只改变**显著度网格内容**的分辨率。DUTS-TE 全量 5019、权重 0.40/0.60/0.00：

| 网格 | A 算法保留率 | B 完美先验 | B−A | 三分线 | 备注 |
|---|---|---|---|---|---|
| 64×48（现役） | 0.975324 | 0.990081 | +0.014757 | 0.0949 | 基准 |
| 128×96 | 0.975484 | 0.990805 | +0.015321 | 0.0951 | A 净增 +0.000160 |
| 256×192 | 0.976149 | 0.991307 | +0.015158 | 0.0956 | A 净增 +0.000665 |

- **A 从 64×48 到 256×192 净增只有 +0.000825**，其中 128×96 就吃掉 80%；**B 只涨 +0.001226**，且 `B−A` 不缩小反而略增 → **分辨率不是瓶颈**。
- 构图（三分线）随分辨率**单调变差**（0.0949 → 0.0951 → 0.0956）。
- 分辨率消融（完美先验内容做粗）：32×24 = 0.988340、16×12 = 0.984079（掉到 16×12 才值 −0.006）。
- **同网格换 RMBG-1.4 拿到 +0.0119 ≈ 分辨率收益的 14 倍** → 优先级明确。
- 建议：**不构成改产线的理由**。若一定要动，取 **128×96**（+246.7 MB / +1 s），**256×192 不值**（+740 MB 换 +0.000665）。
- 旧权重（0.55/0.25/0.20）在同样网格上仍是负值（−0.00558 / −0.00572），说明"分辨率救不了评分规则"。

## 4. 第 4 条：换掉有退化解的目标函数

### 4.1 现有度量 `kept_ratio` 的退化性（独立确认）

- 候选集里 `kept_ratio` 的 argmax **100% 落在最大框（＝整图）**：DUTS-TE src 5019/5019、ECSSD src 995/995。
- "算法框保留率 > 不裁框保留率"＝ **0/5019、0/995**（数学上必然：整图 kept ≡ 1）。
- 所以 kept_ratio 单独看既没有上界意义（上限恒为 1.0），也不能区分"框得好"与"框得小"。

### 4.2 替代度量

| 度量 | 定义 | 意图 |
|---|---|---|
| `H` | `2rc/(r+c)`，`r`=保留率，`c`=构图分（`c=clip(1−d/DMAX,0,1)`，`d`=主体质心到最近三分点的距离，`DMAX=hypot(1/6,1/6)=0.2357`） | 保留率与构图的调和平均，**既要有内容也要摆得正** |
| `Rc` | `r · 1[d ≤ 0.10]` | 只在"构图达标"的图上奖励保留率，构图不达标记 0 |
| `F` | `2|S∩B| / (|S|+|B|)`（`|B|` 为 clip 取整后的框面积） | 类 IoU，惩罚"框太大" |
| `J` | `r · c`（同 `H` 的 `c`） | 乘法版，与 `H` 互为对照 |

DUTS-TE src 全量 5019、算法框 vs **同尺寸**居中框的逐图差（基线权重 / 新权重）：

| 度量 | 基线 0.55/0.25/0.20 | t | 新 0.40/0.60/0.00 | t |
|---|---|---|---|---|
| `H` | **+0.18972** | +46.90 | **+0.20475** | +49.07 |
| `F` | **−0.00275** | −8.77 | **+0.00132** | +3.77 |

### 4.3 关键支点：`F` 是 `kept` 的重述，不是新信息

在"算法框 vs 同尺寸居中框"这个对照下，**逐图 `dF` 与 `dkept` 符号完全相同：5019/5019**；赢率也逐位相同（基线 12.7%，新 19.8%）。所以 `F` 不能当作"换度量后结论变了"的证据。

有效的替换是 **`H` / `Rc`**：它们把"构图摆得正"纳入目标，能同时反映"内容保留"与"构图质量"，并且**把"不裁"从"必然满分"降级为"只有当主体本来就在三分点附近时才满分"**：
- `kept`：整图框恒为 **1.0**（退化解）。
- `J` / `H`：整图框的构图分 `c` 实测均值只有 **0.3637 / 0.3492 / 0.3648**（DUTS-TE / ECSSD / DUT-OMRON，src；src 下兜底框就是整图，`r=1`，故 `J_fb≡c`）；主体正好死中时 `d=DMAX` → `c=0` → `H=0`。
- `Rc`：整图框只有在主体本来就落在三分点 0.10 邻域内时才拿满分，否则记 0。

（注意：这三个度量与 `kept` **不可直接比数值**，只能各自横向比较"算法 vs 居中/不裁"。）

### 4.4 兜底框视角（补充诚实性）

- 兜底框（算法未越过 ABS 门槛时回退的框，src 下即整图）的 `J` ＝ 0.3637 / 0.3492 / 0.3648（三数据集 src）。
- "兜底框 `J` ≥ 算法" 的比例：基线 → 新 ＝ DUTS 44.5% → 37.9%、ECSSD 43.9% → 38.9%、DUT-OMRON 49.4% → 40.5%；三分线 0.1501~0.1534（兜底）vs 0.0907~0.1026（算法）。

- 局限：`J` 的均值仍会被兜底框刷高；`1−kept` 做分母的比值不稳定（单图极值横跨 10¹~10³，不要当稳定数字引用）。

## 6. 建议（按性价比排序）

1. **换显著度模型（唯一大杠杆）**：若要动手，选 **RMBG-1.4**；但必须**按目标口径切片验收**（`src` 收益最大，`3:4` 在 DUT-OMRON 上为负），并接受体积与延时上升（1024² ≈ 1.5 s/图）。若目标只有"少切主体"，收益稳定（6/6 口径更低）。
2. **换目标函数 `kept_ratio` → `H` 或 `Rc`**：零推理成本，直接改变"什么算好框"，能体现构图摆位；建议在报告/调参里改用 `H`，把 `kept_ratio` 降为辅助列。注意它不能与 `kept` 直接比数值。
3. **提升分辨率**：不建议（+0.0008 换 +246 MB）。若要动，只取 128×96。
4. **评分权重**：已在上一轮封顶（`0.40/0.60/0.00` 把 9 个口径的亏空全部翻正），本轮不再投入。

## 7. 局限

- 全部结论都在 **DUTS-TE / ECSSD / DUT-OMRON** 三个真值掩膜数据集上；"完美先验"用真值掩膜，是上界不是可达承诺。
- 三档比例（src/1:1/3:4）只覆盖三种裁剪目标，未覆盖手机端实际的全部预览比例。
- 网格分辨率结论只到 256×192；更高分辨率的趋势未测（但 B 侧已饱和）。
- 目标函数替代度量的"正确性"只能证明它**不与 `kept` 等价**、且在退化点上不奖励"不裁"，**不代表它与人眼偏好一致**（缺主观评测）。
- 未做真机 / APK 验证（本轮明确不做），因此所有"收益"都是离线指标上的收益。
